# 经营分析驾驶舱第二阶段：审计与实施方案

## 目标与不变边界

本阶段将“算得清”的现有首页从经营账簿总览强化为**利润、趋势、风险与行动**优先的轻量经营驾驶舱。实现必须继续以真实账本事实为来源，并保持以下边界：现金结余不等于利润；利润仅来自已结转销售快照；预计分摊不混入实际利润或现金；退款继续按业务日期与冻结快照回滚；行业差异继续由模板能力矩阵表达。

本阶段不新增行业、不重写核算、销售结转、退款、库存或现金算法，不重构页面导航，也不为缺失事实生成演示数据。

## 当前能力审计

| 需求方向 | 当前真实能力 | 数据边界 | 第二阶段处理 |
|---|---|---|---|
| 本月经营利润与毛利率 | `summarizeSales()` 使用销售快照计算收入、直接成本、分摊、资金成本与经营结果 | 仅在存在已结转销售时可信 | 作为首页首要结果，新增按日趋势时沿用同一快照口径 |
| 现金收付趋势 | `getCashTrendSeries()` 只读取实际收付款流水 | 包含本金还款，但不等同利润 | 保留为现金图，不与利润线混图 |
| 商品贡献排行 | 已按销售快照计算商品收入、直接成本与直接贡献 | 当前仅说明直接贡献，未包含全量分摊 | 扩展为 TOP10 与经营贡献解释，继续标注口径 |
| 成本结构与利润桥 | 已有商品成本构成、月度分摊、利润桥 | 商品成本与已结转利润需分开阅读 | 统一图表视觉、增加案例化成本解释，不改变公式 |
| 商品库存 | 商品可选择启用 `stockQuantity`；未启用时不存在库存台账 | 无库存数量时不能推断库存金额或周转天数 | 仅对已启用库存的商品计算占用、近30日销量与可售天数；其余展示待启用状态 |
| 销售实时反馈 | 销售表单已有收入预览，保存时冻结成本快照 | 保存前只能使用当前商品成本作“预计” | 增加预计利润、预计毛利率与本次贡献，并明确不写入实际利润 |
| 消息中心 | 已支持人工发布、有效期、重要程度与已读状态 | 尚无可持久化的自动经营提醒来源 | 先在驾驶舱输出可证实的经营提示；自动写入站内信需单独确认数据与推送策略 |
| 月度目标 | `monthlyBudget` 已存在但未被定义为收入或利润目标 | 语义不明确，不能擅自作为利润目标 | 本期只预留可解释的完成度组件；待产品确认目标口径后接入 |

## 图表与交互规范

所有图表复用现有品牌令牌、移动端 44px 触控热区与轻量点选提示。图表只保留三种基础语法：**折线图**用于按日趋势、**横向柱图**用于商品排行、**环形结构图**用于金额构成。每个图表必须具备标题、口径说明、图例、点选数据提示、空状态与少量数据降级状态。

| 图表 | 真实数据来源 | 默认表现 | 空数据表现 |
|---|---|---|---|
| 最近7天利润趋势 | 按业务日期聚合已结转销售及退款的快照收入与成本 | 单线利润；无成本快照不绘制 | 提示“记录销售后生成真实利润趋势” |
| 收入与成本对比 | 同一按日销售快照聚合 | 双线展示收入与已结转成本 | 不用现金流水替代 |
| 现金流变化 | 现有实际收付款流水 | 保留现有双线与日期抽屉 | 已有空状态 |
| 商品热销/高贡献 | 已结转销售数量、收入与直接贡献 | 横向柱图，最多10项 | 提示记录销售 |
| 成本构成 | 商品直接成本、分摊与资金成本 | 环形结构图与金额提示 | 提示补成本或分摊 |
| 库存资金占用 | 已启用库存商品的 `stockQuantity × 当前完整成本` | 环形结构图或列表 | 提示先启用库存数量 |

## 指标口径与防误导规则

经营健康度不是信用评分，也不是对未来经营结果的预测。它是一个 0–100 的**当前数据完整度与经营状态提示**：销售结转状态、成本完整度、现金是否为负、已结转利润与已启用库存的异常情况分别贡献有限分值。任何缺少销售或成本的数据都会降低“数据就绪度”，而不会被解释为经营差。

环比仅在前一可比较期间存在同口径销售快照时展示；同比仅在去年同月存在同口径数据时展示，否则显示“历史不足，暂不比较”。本月目标完成度在目标口径得到确认前，不将 `monthlyBudget` 擅自解释为收入或利润目标。

库存不足与偏多只适用于已启用库存且近30日存在净销售的商品。可售天数为“当前可售数量 ÷ 近30日平均日净销量”；建议初始标签为不足（不超过3天）、正常（4–30天）、偏多（超过30天），并在页面说明这是基于当前销售速度的辅助提示，不是补货预测。

|---|---|---|---|

## 行业模板适配

页面不按行业名写分支，而读取模板能力矩阵。拥有 `sales` 与 `cash` 的行业可显示经营趋势；拥有 `inventory` 的行业显示库存洞察；拥有 `bom` 或 `production` 的行业强调成本结构与工时；拥有 `customers` 的行业后续可接入客单和复购指标。商贩默认突出收入、利润、库存与现金；零售强调销售与库存；餐饮强调成本结构；手作强调成本、工时与利润。

## 已确认的 P0 产品决策

产品已确认 `monthlyBudget` 统一表示**本月收入目标**，完成度只读取已结转销售收入；不以现金收款替代收入。经营健康度采用“数据就绪度 + 当前经营状态”的可解释评分，不作为预测或信用评分。自动提醒在 P0 只作为首页与经营页的页面内提示，不写入消息中心、不新增未读状态；站内消息自动化留到后续阶段。
