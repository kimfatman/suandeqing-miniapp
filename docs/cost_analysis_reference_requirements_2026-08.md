# 成本分析参考规范提炼

## 产品与入口边界

成本分析必须绑定具体商品，用户首先应看到售价、单位完整成本、单位毛利、毛利率、成本去向和下一步动作。它不新增底部导航；商品详情应提供清晰入口，经营页可作为次级入口。页面的商品选择必须同步更新所有分析内容。

## 信息顺序

页面按“结论优先 → 成本结构 → 异常 → 趋势 → 模拟 → 保本 → 建议”组织。核心结论使用“售价 − 单位成本 ＝ 单位毛利”和毛利率。成本结构使用简洁环形或比例结构以及横向列表，不使用Excel式表格。异常采用偏高/正常/偏低等轻量状态，避免整块红色。

## 计算边界

成本构成、保本线和模拟必须来自当前商品的材料/直接成本、月度间接成本分摊和资金成本口径。已发生经营结果只能基于销售时冻结的成本快照；售价、成本、销量模拟应显式标为预计测算，不能混入现金或已结转利润。无商品、无成本、计算中和异常状态必须可理解并提供“添加成本”行动。

## 移动端与品牌

采用算得清现有蓝色、绿色、橙色和红色状态体系，克制使用“＋、−、＝、¥、%”作为计算语言。采用8px网格、左右16px、卡片间距12–16px、核心卡片圆角16–20px、主按钮48–52px、所有触控区域至少44px，并在375、390、414宽度下检查文字、按钮、图表和信息密度。
