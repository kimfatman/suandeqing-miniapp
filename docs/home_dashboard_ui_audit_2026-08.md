# 首页经营驾驶舱 UI 审计

## 已通过的层级检查

390×844 首屏已形成“经营结果 → 经营状态与现金情况 → 趋势”的明确阅读顺序。结果卡只显示真实销售快照利润；未完成销售结转时仍会回退到实际现金口径。状态、现金、商品贡献与异常模块均保留来源说明，未引入行业均值、环比或待收待付等无来源指标。

## 需立即修正的比例问题

原全局固定“记一笔”按钮会在滚动至趋势详情与商品模块时覆盖卡片右下角内容。现已将其收纳为底部导航中央的 44px 以上触控项；复核确认趋势日期选择器、单日净收付和商品区域不再被遮挡，统一入口能力保持可用。

## 后续核验清单

发布前应复核 375、390、414 宽度下的结果卡计算式、现金三段式、趋势日期选择、商品 Top5、异常/空状态、快捷操作及底部导航；同时确认盈利、亏损、待销售结转和无异常状态均保持可读。

## 375 / 414 宽度审计

375 宽度下，结果卡公式、状态/现金双卡和中心记一笔导航均未溢出。414 宽度下，现金情况卡的三段金额因沿用较大正文金额在单卡中出现省略号；需将该高密度公式使用固定的紧凑金额字号和更稳定的列宽，确保“已收 − 已付 ＝ 结余”每个数字完整可读。

金额字号已收紧后，414 宽度下三段金额均可完整读取。390 下半屏复核确认：商品排行的名称、销售额、直接贡献率和横向进度条能同时扫读；无异常状态使用品牌笑脸弧线但不抢占业务结论；行动卡和快速操作保持与底部中心记一笔入口的视觉区分，内容未被固定导航遮挡。
