# 核算模型与数据口径

## 三条不可混淆的口径

| 口径 | 来源 | 用于 | 不应被误读为 |
|---|---|---|---|
| 实际现金 | 手工流水、材料采购、销售收款、退款、本金还款 | 现金结余、现金趋势、现金明细 | 经营利润 |
| 已结转经营结果 | 有效销售收入减销售时冻结的直接、间接和资金成本 | 经营结果、利润桥、商品销售贡献 | 当前材料价格下的预计利润 |
| 当前/预计完整成本 | 当前 BOM/材料、当前月度分摊和资金成本设置 | 定价建议、成本分析、保本和模拟 | 已发生销售的历史成本 |

## 商品成本公式

```text
单位直接成本 = 材料/进货明细 + 包装 + 直接人工 + 损耗或出成调整
单位经营分摊 = 本期固定及隐形成本 × 商品分摊份额 ÷ 该商品预计产量
单位完整成本 = 单位直接成本 + 单位经营分摊 + 单位资金成本
预计单位毛利 = 当前售价 − 单位完整成本
预计毛利率 = 预计单位毛利 ÷ 当前售价
保本售价 = 单位完整成本
```

当使用月度间接成本计划时，计划可按产量、工时或销售额分摊，并支持商品权重、有效开始/结束日期及按天折算。分摊明细必须能回溯至房租、人工、水电、折旧、软件和其他费用。

## 销售快照

记录销售时保存以下核心事实：业务日期、数量、成交单价、单位直接成本、固定/隐形成本、资金成本、月度间接成本和对应计划信息。后续材料单价、商品成本、分摊方案或售价变化只能影响**未来预计**，不得改写过去销售的利润。

退款以退款日期冲减收入和相应成本；全额退款会使销售撤销。录错删除则移除原始销售及其关联收款、退款和成本结转，二者必须保持不同的业务语义。

## 成本分析页面

成本分析始终绑定一个商品。页面中的成本结构、保本线和模拟来自当前成本与定价；趋势仅展示有效销售中保存的单位直接成本快照；模拟价格、成本与销量仅在浏览器状态中计算，不保存也不改写历史账本。缺失成本或售价时，页面必须引导用户补齐数据，而不是显示虚构利润。

## 数据质量检查

1. 不允许未定价商品以零价完成销售。
2. 同单位材料换算固定为 1:1；跨单位必须有正数换算系数。
3. 月度分摊的总额与所有商品分摊合计应可对账。
4. 销售、退款与删除会同步核对收入、成本和库存。
5. 图表只绘制真实流水、有效销售或用户填写的预计分摊，不填充演示数据。
