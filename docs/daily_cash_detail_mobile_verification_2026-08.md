# 按日现金明细抽屉：移动端验证记录

## 验证范围

本轮验证覆盖首页“现金收付趋势”中的日期选择与按日明细抽屉。明细仅重读已保存的 `LedgerRecord`；销售利润、成本快照和预计分摊不会进入当天收付款或净收付计算。

| 视口 | 验证结果 | 关键结论 |
|---|---|---|
| 375 × 844 | 通过 | 日期、收款/付款/净收付三段式、来源标签和返回按钮均完整可读。 |
| 390 × 844 | 通过 | 趋势日期可打开抽屉，真实流水与净收付一致，关闭后回到趋势。 |
| 414 × 844 | 通过 | 抽屉宽度、信息提示和底部操作区比例稳定，无金额或文字截断。 |

## 口径检查

抽屉的收款、付款与净收付与趋势图复用同一日期与现金流水来源。销售退款和本金还款作为实际付款保留展示，但不被表述为利润成本。无流水日期仍可打开抽屉并显示空状态，避免将“图表范围内无发生”误认为数据缺失或经营利润为零。
