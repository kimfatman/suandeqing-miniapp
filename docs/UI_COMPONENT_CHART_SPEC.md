# 算得清：全站 UI 组件与图表规范

本规范应用于首页、商品、成本分析、采购、销售、退款、经营、我的、消息、数据管理，以及所有高频录入与确认弹层。其目标是让用户在不同页面看到同一套**间距、层级、颜色、状态与图表表达**，但不改变账本、销售快照、现金流或分摊的计算逻辑。

| 维度 | 统一规则 | 应用边界 |
|---|---|---|
| 页面表面 | 白色主表面、淡灰辅助表面、细分割线与轻阴影 | 页面卡片、列表、报表与设置分组 |
| 触控与输入 | 主操作 48px、普通操作 40px、最小触控 44px | 按钮、筛选、日期、表单、抽屉操作区 |
| 状态 | 绿色为正常、琥珀色为待关注、红色为风险、蓝色为可操作 | 库存、消息、经营异常、校验与标签 |
| 空状态 | 虚线边框、明确原因、下一步操作，禁止制造示例经营数据 | 图表、商品、库存、消息、成本与销售 |
| 图表 | 收入为蓝、成本为绿、提示为琥珀、风险为红；共享标题、图例、提示、范围选择与空态 | 现金、利润、收入成本、商品贡献、成本构成、库存与定价分析 |

> **核算边界不随视觉规范改变。** 现金图表只展示实际收付；经营利润只来自已结转销售快照；预计分摊和定价测算不得被展示为已发生利润或现金。

## 验收要求

所有页面与弹层必须保留可见焦点、44px 触控热区、390px 宽度下无横向溢出，并在有数据、无数据与风险状态下维持可读层级。图表必须有明确口径说明、可区分图例、触控提示或等价日期选择方式，且空数据提供真实下一步操作。

## 本轮移动端回归

商品页已验证商品列表、盈利状态、单件成本/利润、成本分析入口与底部导航；经营页已验证利润主卡、现金流/利润分析分段、口径提示、销售结转与图表区域。两页均在 390×844 真实浏览器视口下无横向溢出。
