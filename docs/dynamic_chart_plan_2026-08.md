# 动态图表改造方案

本轮图表以“先分清口径，再展示趋势”为原则。所有现金图仅使用已发生的收款和付款；利润图仅使用销售当时冻结的收入与成本快照；月度分摊图只服务于成本预估与定价，不写成已经发生的经营结果。

| 优先级 | 图表 | 数据来源 | 交互 | 口径边界 |
|---|---|---|---|---|
| P0 | 现金收付趋势 | 选定期间的 `dailySeries` | 点按日期查看收款、付款和当日净额 | 统计实际收付款；本金影响现金但不作为经营成本 |
| P0 | 单件成本构成 | 商品直接成本、经营分摊、资金成本 | 点按成本层查看金额与占比 | 用于当前商品单件完全成本，不改写历史销售快照 |
| P0 | 销售利润桥 | 销售收入、直接成本、已结转间接成本、资金成本、经营结果 | 点按每一步查看增减含义 | 仅在存在有效销售结转时展示；不把现金付款当利润成本 |
| P0 | 商品经营贡献 | 按商品聚合已发生销售快照 | 点按商品查看收入、已结转直接成本与直接贡献 | 当前已实现；房租、人工等分摊仍在成本分析中单独查看 |
| P1 | 月度分摊分布 | 当前分摊方案的商品权重、产量/工时/销售额 | 点按商品查看分摊总额与每件分摊 | 是预计分摊/定价依据，不等于实际现金付款或已实现利润 |
| P2 | 采购价格与库存健康 | 材料采购历史与最低库存阈值 | 按材料、日期对比 | 当前账本未保存完整采购价格历史或补货阈值，不制作推测性图表 |

本次先完成 P0 三类图表，并保留 P1 图表需要的数据边界。所有图表均提供空状态、触控选择和减少动画偏好支持；移动端不依赖悬停操作。
